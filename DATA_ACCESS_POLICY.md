# Restricted dataset policy

The original and processed LTE/Wi-Fi RF fingerprint measurements, transmitter identities associated with measurements, reference coordinates, log identifiers, route-fold assignments, per-sample predictions, residuals, trained models, and detailed checkpoints are **not publicly distributed**.

This repository contains MATLAB source code and documentation only. Any separately published aggregate results exclude individual fingerprint records and positioning traces.

Researchers may request access to restricted research data, but release is subject to approval from the applicable rights holders and any research-use conditions. Access is not guaranteed. The public code alone cannot reproduce the reported numerical results without authorized input data.

Do not commit restricted datasets, MAT archives, individual predictions, or route-fold mappings to GitHub. No public dataset DOI is claimed.
